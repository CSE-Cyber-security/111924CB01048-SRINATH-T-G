# Week - 3: Fibonacci Series

## Problem

Write a Python program to print the Fibonacci series for `n` terms.

## Input

```text
Enter the number of terms: 7
```

## Output

```text
Fibonacci Series:
0 1 1 2 3 5 8
```

## Description

The Fibonacci series is a sequence where each number is obtained by adding the previous two numbers.

The program starts with:

```text
0 1
```

Then it generates the next numbers:

```text
0 1 1 2 3 5 8
```

## How to Run

1. Install Python.
2. Save the program as `fibonacci.py`.
3. Open the terminal in the project folder.
4. Run the following command:

```bash
python fibonacci.py
```

5. Enter the number of terms.

## Example

```text
Enter the number of terms: 7
Fibonacci Series:
0 1 1 2 3 5 8
```
