# Week - 2: Factorial Program

## Problem

Write a Python program to find the factorial of a given number.

## Input

```text
Enter a number: 5
```

## Output

```text
Factorial of 5 = 120
```

## Files

- `factorial.py` - Python program to calculate the factorial.
- `output.png` - Screenshot of the program output.

## How to Run

1. Make sure Python is installed.
2. Open a terminal in this folder.
3. Run:

```bash
python factorial.py
```

4. Enter a number when prompted.

## Example

```text
Enter a number: 5
Factorial of 5 = 120
```
