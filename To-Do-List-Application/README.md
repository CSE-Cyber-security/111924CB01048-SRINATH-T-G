# To-Do List Application

A simple, responsive task-management web application built with HTML, CSS, and vanilla JavaScript.

## Features
- Add new tasks
- Mark tasks as completed or pending
- Delete tasks
- Filter tasks by All, Pending, and Completed
- View task counts and summaries
- Responsive layout for desktop and mobile

## Project files
- `index.html` — application structure
- `style.css` — layout and styling
- `script.js` — task interactions and DOM manipulation
- `screenshots/output-screenshot.png` — sample output screenshot

## How to run
1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Add, complete, filter, or delete tasks.

No extra packages or build tools are required.

## GitHub submission
Create a repository named `To-Do-List-Application`, then upload all files and the `screenshots` folder.

## Technologies used
HTML5, CSS3, JavaScript (DOM manipulation).
